    node reference
      Server control

      The server is a Node process inside your Termux session. Stopping it ends everything the app is holding: queued prompts and images still to download are gone, while prompts already handed to ComfyUI keep running there and finish on their own.

      Start it again with bash start.sh in Termux. The page confirms the shutdown by watching the server stop answering, not by trusting the reply.
